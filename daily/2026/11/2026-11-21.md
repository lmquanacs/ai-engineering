## TL;DR
1. **Spring AI 2.1.0 GA (with 2.0.3) fixes 13 CVEs**, one Critical in the Redis semantic cache. The RCs don't have the fixes, so move now; also expect a required `SemanticCacheScopeResolver` bean, default tool-call limits (40 per tool / 150 per turn) and ChatMemory deprecated in favour of the new Session API. Built on Spring Boot 4.2.0, which deprecates `RestTemplate` support.
2. **MCP bridges are leaking to the browser:** Supergateway's stdio-to-WebSocket mode can be driven by any web page (CVE-2026-132121, no fix yet); Obot < 0.27.0, LibreChat < 0.8.8 and AWS's document-loader MCP server < 1.0.21 also have CVEs.
3. **Pydantic AI CVE-2026-133505:** serialized tool results can be rebuilt as file objects (SSRF, credentialed `s3://` reads) in apps that store and reload history. Run ≥ 2.66.0 (or 1.107.10).
4. **Claude Code 2.1.330:** `deniedMcpServers` name entries now block only the named claude.ai connector (deny by URL to block all), more broad `rm` commands ask, and `/loop` runs up to 30 days. **Codex 0.171** makes GPT-6.2 Sol the default catalog model, so pin models in CI.
5. **Action items:** Claude Opus 4.8 fast mode removed **30 Nov** · Copilot retires six models **14 Dec** and MAI-Code-1.1-Flash **18 Dec** · Gemini 4 logprobs requests reportedly return 400 · NeMo Guardrails 0.25 deprecates `LLMRails`/Colang · Google ADK 2.15 removes the Visual Agent Builder.

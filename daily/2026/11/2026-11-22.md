## TL;DR
1. **Vercel AI SDK 7.0.178** fixes signed tool approvals: auto-denied tool calls were signed too, so a client controlling history could approve them. Upgrade **and rotate `experimental_toolApprovalSecret`**, because old signatures stay valid.
2. **MCP "read-only" modes keep failing:** mcp-ssh-manager (≥ 3.8.5), SurrealDB (≥ 4.0.0) and ArcadeDB (≥ 26.11.1) all let writes or commands through tools labelled read-only; plus fixes for codebase-memory-mcp, k8s-mcp-server and jupyter-mcp-server.
3. **Daytona Python SDK 2.x** is now what `pip install daytona` gives you, and root imports such as `Sandbox` raise `ImportError`. Pin `daytona<1` or migrate.
4. **AWS pre-re:Invent:** AgentCore Gateway can filter streamed model output through interceptors, Runtime Instances get G7 GPUs, Bedrock web search adds languages and a `country` field, and S3 Vectors / DynamoDB get richer vector filters.

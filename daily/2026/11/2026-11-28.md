## TL;DR
1. **Apache Airflow LLM decorators (CVE-2026-120353):** `@task.llm`, `@task.agent`, `@task.llm_sql` and several non-AI decorators rendered Jinja a second time on the worker. Text injected into a prompt or Dag run conf could then run commands and read connection secrets. Upgrade `apache-airflow-providers-common-ai` to 1.2.0, `-standard` to 1.22.0, `-common-sql` to 3.0.0 and `-cncf-kubernetes` to 11.0.0.
2. **Copilot CLI 1.0.117:** approving an MCP server's tools could also approve Copilot's built-in shell and memory requests when the server's name matched a built-in permission type. Update. Separately, from **2026-12-30** Copilot code review usage by licensed members is billed to the repo's organization unless an admin picks **Member**.
3. **LangChain4j 1.24.1** has no release notes, but `ApacheTikaDocumentParser` now stops at 10,000,000 characters by default and throws on longer documents. Set `maxCharacters(n)` (`-1` for no limit) before upgrading a RAG ingestion pipeline.
4. **OTel GenAI semantic conventions v0.1.0** is the first standalone release, and it renames token-usage and duration metrics, `cache_creation` → `cache_write` and `mistral_ai` → `mistral`. Map your dashboards and cost queries before your instrumentation libraries adopt it.
